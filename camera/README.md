# AI Camera Pro
Standalone Android camera app module for PocketTool's GitHub Actions build.

Features: CameraX live preview, rear/front camera switching, tap-to-focus, torch, zoom, still photo capture and Full HD video recording. Media is saved locally to the device's Pictures/AI Camera Pro and Movies/AI Camera Pro folders.

Camera output quality and available lens features depend on the phone hardware. 4K is not forced; this build uses broadly supported Full HD video quality.
